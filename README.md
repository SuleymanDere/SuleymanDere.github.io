# HAVAC Website

HAVAC'ın havalandırma ve iklimlendirme çözümlerini tanıtan, bağımlılıksız statik web sitesi.

## Yerelde çalıştırma

Bu klasörde bir yerel web sunucusu başlatın ve tarayıcıda açın. VS Code içindeki Live Server eklentisi kullanılabilir. `index.html` dosyasını doğrudan açmak da temel görünüm için yeterlidir.

## Yayınlama

Bu proje statik olduğundan GitHub Pages ile yayınlanabilir:

1. Dosyaları GitHub deposunun kök dizinine koyun.
2. GitHub'da **Settings → Pages** bölümüne gidin.
3. **Deploy from a branch** seçeneğini seçip yayınlanacak dalı ve `/ (root)` klasörünü belirtin.

## Yayından önce tamamlanacaklar

- İletişim bilgileri, adres ve sosyal medya bağlantılarındaki yer tutucuları gerçek bilgilerle değiştirin.
- İndirme ve katalog bağlantılarına gerçek PDF dosyalarını ekleyin.
- Formlar şu anda yalnızca demo bildirimi gösterir; üretimde bir form servisine veya sunucu tarafı uç noktaya bağlanmalıdır.
- Unsplash görsellerini lisanslı, proje için optimize edilmiş yerel görsellerle değiştirin.
